# BYD AutoLock — iOS / watchOS

BYD 전기차 자동 잠금/해제 앱의 비공식 iOS 포팅 프로젝트입니다.
Android [BydAutoLock](https://github.com/PoorGrammerA/BydAutoLock)을 네이티브 Swift/SwiftUI로 완전 재구현했습니다.

> **비공식 프로젝트**입니다. BYD 자동차와 무관하며, 사용에 따른 책임은 사용자 본인에게 있습니다.

---

## 주요 기능

### iPhone 앱

| 기능 | 설명 |
|---|---|
| **자동 잠금 해제** | BLE RSSI가 임계값 이상이면 자동 잠금 해제 |
| **자동 잠금** | RSSI가 임계값 이하로 떨어지면 자동 잠금 |
| **예측 사전 해제** | RSSI 상승 기울기(선형 회귀)로 접근을 미리 예측, 도착 전 선제적으로 해제 |
| **잠금 결과 검증** | 자동 잠금/해제 후 35초 뒤 실제 차량 상태를 확인, 불일치 시 재시도 후 알림 |
| **신호 소실 보호** | BLE 신호 끊김 60초 후 안전 잠금 (30초 지연 알림, 복구 시 자동 취소) |
| **RSSI 필터링** | EMA 지수 이동 평균 + 이상값 제거(선형 회귀 기반) + 히스테리시스 |
| **주행 중 잠금 차단** | CoreMotion으로 주행 감지 시 자동 잠금 및 알림 스킵 |
| **차량 상태 조회** | 잠금 여부, 배터리 %, 주행 가능 거리, 실내 온도, 에어컨 상태 |
| **수동 제어** | 앱 내 잠금/해제 버튼 (결과 폴링으로 즉시 확인) |
| **에어컨 수동 제어** | 앱 내 에어컨 켜기/끄기 버튼 |
| **에어컨 자동 제어** | 잠금 해제 시 자동 켜기 / 잠금 시 자동 끄기 (온도·풍속·순환 설정 가능) |
| **지오펜싱** | 차량 이탈 시 BLE 스캔 자동 중단, 복귀 시 재개 (반경 50~500m 조정 가능) |
| **주차 위치 저장** | 주차 시 GPS 좌표 자동 기록, Apple 지도 연동 ("내 차 찾기") |
| **백그라운드 동작** | 앱 종료/화면 잠금 상태에서도 자동 잠금/해제 동작 |
| **15개 지역 서버** | KR / EU / JP / SG / AU / BR / MX / NO / UZ / KZ / IN / ID / VN / SA / OM |
| **테마 설정** | 라이트 / 다크 / 시스템 선택 가능 |
| **디버그 로그** | BLE·API·Geofence·GPS·Motion 이벤트 SQLite 저장, 태그 필터·공유 지원 |

```
iPhone App
├── AutoLockService          ← BLE 스캔 + RSSI 처리 + API 호출 (@MainActor)

├── WatchMainView            ← SwiftUI UI
├── WatchConnectivityManager ← iPhone 명령 전송 / 상태 수신

Widget Extension
└── BydAutoLockWidget        ← WidgetKit (App Group으로 데이터 공유)
```

## 빌드 방법

### 요구 사항

- Xcode 15 이상
- iOS 16+ / watchOS 10+ 실기기
- Apple 계정 (무료 계정으로 사이드로딩 가능)
- `xcodegen` (`brew install xcodegen`)

### 빌드 단계

```bash
# 1. 저장소 클론
git clone https://github.com/GeyuongGongPark/BydAutoLock-iOS.git
cd BydAutoLock-iOS

# 2. project.yml에서 Bundle ID 변경
# PRODUCT_BUNDLE_IDENTIFIER: com.yourname.bydautolock
# App Group: group.com.yourname.bydautolock (iPhone + Widget entitlements)

# 3. Xcode 프로젝트 생성
xcodegen generate

# 4. Xcode로 열기
open BydAutoLock.xcodeproj

# 5. Product → Archive
```

### 무료 계정 사이드로딩 (AltStore / Sideloadly)

```bash
# Archive 후 IPA 추출
ARCHIVE=$(ls -t ~/Library/Developer/Xcode/Archives/**/*.xcarchive | head -1)
mkdir -p Payload
cp -r "$ARCHIVE/Products/Applications/BYD AutoLock.app" Payload/
zip -r BydAutoLock.ipa Payload
```

1. AltStore / Sideloadly로 iPhone에 설치
2. **설정 → 일반 → VPN 및 기기 관리**에서 개발자 신뢰

> 무료 계정은 7일마다 재서명 필요. 슬롯 3개 한도.

## 초보자 설정 가이드

처음 사용하신다면 이 순서대로 따라하세요.

### 준비물 확인

앱을 쓰기 전에 아래 세 가지를 먼저 준비해야 합니다.

| 준비물 | 확인 방법 |
|---|---|
| **BYD 계정** | BYD 공식 앱에서 가입한 이메일 + 비밀번호 |
| **차량 PIN (작동 비밀번호)** | BYD 앱 → 차량 제어 → 비밀번호 설정에서 6자리 숫자 설정 |
| **지역 확인** | 차량을 구입한 나라 (한국 = KR, 유럽 = EU 등) |

> **PIN을 설정하지 않으면 자동 잠금/해제가 동작하지 않습니다.**
> BYD 앱에서 미리 설정해두세요.

---

### Step 1 — 계정 입력

1. 앱을 열고 오른쪽 상단 **메뉴(☰)** 버튼을 탭합니다
2. **BYD 계정 설정**을 탭합니다
3. 아래 항목을 입력합니다:
   - **이메일 / 아이디**: BYD 앱 로그인에 쓰는 이메일
   - **비밀번호**: BYD 앱 비밀번호
   - **PIN**: BYD 앱에서 설정한 6자리 작동 비밀번호
   - **지역 서버**: 차량 구입 국가 선택 (한국 = **KR**)
4. **로그인 및 저장** 버튼을 탭합니다
5. "로그인 성공" 메시지가 뜨면 완료입니다

> 로그인 실패 시: 지역 서버가 맞는지 확인하세요. 한국 구입 차량은 반드시 KR을 선택해야 합니다.

---

### Step 2 — 블루투스 기기 연결

1. **메뉴 → 블루투스 기기 설정**을 탭합니다
2. **iPhone의 블루투스가 켜져 있어야** 합니다
3. **차량 근처(약 10m 이내)**에 있어야 차량 BLE 신호가 잡힙니다
4. 목록에서 내 차량의 이름을 탭하면 자동으로 저장됩니다

> 목록에 차량이 안 보일 경우:
> - 차량 문이 잠겨있어도 BLE 신호는 발신됩니다 (시동 불필요)
> - 화면 상단 **검색** 버튼을 탭해서 스캔을 시작하세요
> - 차량 이름을 모르면 가장 신호 세기(dBm 값이 높은 것, 예: -55 dBm)가 강한 항목이 내 차일 가능성이 높습니다

---

### Step 3 — 차종 선택

1. **메뉴 → 차량 정보**를 탭합니다
2. 내 차종을 선택합니다 (ATTO 3 / SEALION 7 / DOLPHIN 등)
3. **저장**을 탭합니다

> 차종을 선택하면 해당 차량에 최적화된 BLE 감도 설정이 자동으로 적용됩니다.

---

### Step 4 — 알림 허용

1. **메뉴 → 알림 설정**을 탭합니다
2. 알림 권한이 **"거부됨"** 으로 표시되면 **"시스템 설정에서 권한 허용"** 버튼을 탭합니다
3. iOS 설정에서 BYDAutoLock 알림을 **허용**으로 변경합니다
4. 앱으로 돌아와서 받고 싶은 알림 종류를 켭니다:
   - **잠금 / 해제**: 자동으로 잠기거나 열릴 때 알림
   - **신호 끊김 / 복구**: 차량 BLE 신호가 끊겼을 때 알림
   - **차량 배터리 부족**: 배터리가 설정값 이하로 떨어질 때 알림

---

### Step 5 — 서비스 시작

1. 앱 메인 화면으로 돌아옵니다
2. 화면 중앙의 **자동 잠금 서비스** 토글을 켭니다
3. 상태가 **"재연결 중"** → **"연결됨"** 으로 바뀌면 정상 동작 중입니다

이제 스마트폰을 들고 차에 가까이 가면 자동으로 문이 열리고, 멀어지면 잠깁니다.

---

### 반응 거리 조정 (RSSI 임계값)

기본값으로도 대부분 잘 동작하지만, 반응 거리를 조정하고 싶다면:

**메뉴 → RSSI 임계값 설정**

| 설정 항목 | 설명 | 기본값 | 조정 방법 |
|---|---|---|---|
| **잠금 해제 임계값** | 이 거리 안에 들어오면 문이 열립니다 | -70 dBm | 너무 멀리서 열리면 낮추세요 (예: -65) |
| **잠금 임계값** | 이 거리 밖으로 나가면 문이 잠깁니다 | -85 dBm | 너무 가까이서 잠기면 낮추세요 (예: -80) |

> **dBm 값이 클수록(0에 가까울수록) 가까운 거리입니다.**
> 예: -55 dBm = 매우 가까움 / -85 dBm = 멀리 있음

> 잠금 해제 임계값은 반드시 잠금 임계값보다 커야 합니다.
> 예: 잠금 해제 -70, 잠금 -85 (올바름) / 잠금 해제 -85, 잠금 -70 (오류)

---

### 에어컨 자동 제어 (선택)

차에 탑승하기 전 에어컨을 미리 켜고 싶다면:

**메뉴 → 에어컨 설정**

- **잠금 해제 시 자동 켜기**: 차에 가까이 갈 때 에어컨이 자동으로 켜집니다
- **잠금 시 자동 끄기**: 차에서 멀어질 때 에어컨이 자동으로 꺼집니다
- **목표 온도** / **바람 세기** / **공기 순환 모드** 조정 가능

> 에어컨은 최대 20분간 동작 후 자동 종료됩니다.

### 자주 묻는 질문 (FAQ)

**Q. 자동으로 잠기거나 열리지 않아요**

1. 서비스 상태가 **"연결됨"** 인지 확인하세요
2. 메뉴 → 블루투스 기기 설정에서 차량이 선택되어 있는지 확인하세요
3. BYD 계정 설정에서 PIN이 입력되어 있는지 확인하세요
4. BYD 앱에서 **작동 비밀번호(PIN)** 를 설정했는지 확인하세요

**Q. 문이 너무 멀리서 열려요 / 너무 가까이 가야 열려요**

메뉴 → RSSI 임계값 설정에서 잠금 해제 임계값을 조정하세요.
- 더 가까이서 열리게: 값을 낮추세요 (예: -70 → -65)
- 더 멀리서 열리게: 값을 높이세요 (예: -70 → -75)

**Q. 앱이 백그라운드에 있을 때 동작 안 해요**

1. iOS 설정 → BYDAutoLock → 위치 → **"항상"** 으로 설정되어 있는지 확인하세요
2. iOS 설정 → BYDAutoLock → **백그라운드 앱 새로 고침** 이 켜져 있는지 확인하세요
3. iOS 설정 → BYDAutoLock → 블루투스 접근이 허용되어 있는지 확인하세요

**Q. 주행 중에 문이 잠겨요**

정상 동작입니다. 주행 중에는 BLE 신호가 약해지면서 이탈로 감지될 수 있습니다.
앱은 CoreMotion으로 주행을 감지해 이 경우를 차단하지만, 감지 지연이 있을 수 있습니다.
메뉴 → RSSI 임계값 설정에서 잠금 임계값을 낮추면(예: -85 → -90) 완화됩니다.

**Q. "작동 비밀번호를 설정해주세요" 알림이 와요**

BYD 공식 앱에서 원격 제어용 PIN(작동 비밀번호)을 설정하지 않은 경우입니다.
BYD 앱 → 차량 제어 → 비밀번호 설정에서 6자리 숫자를 설정한 뒤, 이 앱 메뉴 → BYD 계정 설정에서 PIN을 다시 입력하세요.

**Q. 배터리 소모가 많아요**

- 메뉴 → RSSI 임계값 설정 → **BLE 스캔 모드**를 "저전력 (Low Power)"으로 변경하세요
- 지오펜싱이 활성화되어 있으면 차량 근처에서만 BLE 스캔이 동작합니다

**Q. 데모 모드가 뭔가요?**

BYD 계정이 없어도 앱의 주요 기능을 체험할 수 있는 모드입니다.
메뉴 → BYD 계정 설정 → **"데모 모드로 체험"** 버튼으로 진입할 수 있습니다.
실제 차량에는 연결되지 않으며, 실제 잠금/해제 동작은 발생하지 않습니다.

## BLE 직접 제어 설정 가이드

BLE 직접 제어는 BYD 클라우드 API 없이 차량 BLE 신호로 직접 잠금/해제하는 기능입니다.
인터넷 없이도 동작하며, API 방식보다 응답이 빠릅니다.

> **전제**: BLE 직접 제어를 포함한 앱의 모든 기능은 BYD 계정 ID/PW 설정이 필수입니다.
> ID/PW가 없으면 REST API(자동 잠금/해제)와 BLE 직접 제어 등록 모두 동작하지 않습니다.
> 먼저 **설정 → BYD 계정 설정**에서 차량이 등록된 BYD 계정 정보를 입력하세요.

### 등록 방법

1. **설정 → BLE 직접 제어 → "BLE 직접 제어 등록"** 버튼 탭
2. **자가 승인** 경로로 자동 진행됩니다 — 별도 QR 스캔 불필요
3. 자가 승인 API가 실패한 경우 **QR 스캔** 경로로 자동 전환됩니다

### 자가 승인 경로 (일반)

앱에 저장된 ID/PW로 BYD API를 직접 호출해 자동 승인합니다.

> **주의**: 자가 승인은 앱에 저장된 ID/PW로 BYD 서버에 직접 승인 요청을 보냅니다.
> 반드시 **해당 차량이 등록된 BYD 계정**과 동일한 ID/PW를 사용해야 합니다.

```
등록 버튼 탭
  → QR 코드 UUID 생성
  → 저장된 계정으로 자동 승인 (scanWatchLoginAction / Determine)
  → 토큰 교환 (gain/token)
  → 차량 정보 + BLE 키 조회 (gain/vehicle + gain/bluetooth)
  → dkey 저장 완료
```

### QR 스캔 경로 (자가 승인 실패 시 fallback)

자가 승인 API 오류 등으로 자동 승인이 실패한 경우, QR 스캔 경로로 자동 전환됩니다.

1. 화면에 QR 코드가 표시됩니다
2. QR 화면을 **스크린샷**으로 캡처합니다
3. BYD 공식 앱을 열고, QR 스캔 화면에서 **갤러리에서 불러오기**로 캡처한 QR 이미지를 선택해 승인합니다
4. 이 앱으로 돌아오면 자동으로 토큰 교환 및 dkey 저장이 진행됩니다

### 계정 구조와 권장 사용 방식

BYD 공식 앱은 **메인 계정 + 보조 계정(여러 개 등록 가능)** 구조입니다.

| 계정 | 역할 |
|---|---|
| 메인 계정 | 차량 소유자 계정. 차량 등록, BLE 키 발급 권한 보유 |
| 보조 계정 | 공유 계정. REST API 호출 가능하나 BLE 키 발급 권한 없음 |

**권장 플로우 (보조 계정으로 평소 운영 시)**

1. **평소**: 보조 계정으로 앱 로그인 → 자동 잠금/해제 (REST API) 사용
2. **BLE 직접 제어 등록 시에만**: 설정에서 메인 계정으로 전환 → 자가 승인 진행
3. **등록 완료 후**: 다시 보조 계정으로 전환

> dkey는 로그아웃해도 기기 Keychain에 유지됩니다.
> 계정을 전환해도 등록된 dkey는 그대로 남아 BLE 직접 제어가 정상 동작합니다.

### 주의사항

- 차량을 변경하거나 dkey가 만료된 경우 재등록이 필요합니다.
