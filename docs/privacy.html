BYD AutoLock은 사용자의 개인정보를 개발자 서버로 수집하거나 제3자와 공유하지 않습니다. 모든 민감 정보는 사용자 기기 내에서만 처리됩니다.

2. 외부 서버 전송

앱은 차량 제어 및 상태 조회를 위해 BYD 공식 서버 (byd.auto)에만 통신합니다. 개발자가 운영하는 별도 서버는 없으며, 사용자 정보가 개발자에게 전달되지 않습니다.

전송 대상전송 내용목적
BYD 서버 (byd.auto) 계정 인증 토큰, 차량 제어 명령 차량 잠금/해제 · 상태 조회

3. 제3자 공유

사용자의 어떠한 정보도 제3자와 공유하지 않습니다. 광고, 분석, 마케팅 목적의 SDK가 포함되어 있지 않습니다.

4. 데이터 보관 및 삭제

모든 데이터는 사용자 기기 내에 저장됩니다. 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다. 개발자는 사용자의 데이터를 보유하지 않습니다.

5. 아동 개인정보

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

6. 비공식 앱 안내

BYD AutoLock은 BYD가 공식적으로 제작하거나 승인한 앱이 아닌, 독립 개발자가 만든 비공식 서드파티 앱입니다. BYD의 공개 API를 사용하며, 사용자가 자신의 BYD 계정으로 직접 로그인하여 동작합니다.

8. 방침 변경

BYD AutoLock does not collect personal information on developer servers or share it with third parties. All sensitive data is processed solely on the user's device.

1. Information We Collect and How We Use It

InformationPurposeStorage
BYD Account (ID · Password) Authentication with BYD servers and vehicle control API calls On-device only (iOS Keychain / App Group)
Location Geofencing based on parking location — determining vehicle proximity On-device only, never transmitted externally
Bluetooth (BLE) BYD vehicle BLE signal detection — distance measurement and auto lock/unlock Not stored (real-time processing only)
Motion Sensors Stationary/moving detection — reducing unnecessary BLE scans to save battery Not stored (real-time processing only)
App Diagnostic Logs Error diagnosis and feature improvement On-device only; exportable by user

2. Data Transmitted to External Servers

The app communicates only with BYD's official servers (byd.auto) for vehicle control and status queries. The developer does not operate any separate server, and no user information is transmitted to the developer.

DestinationData SentPurpose
BYD Server (byd.auto) Account authentication token, vehicle control commands Vehicle lock/unlock · status queries

3. Third-Party Sharing

We do not share any user information with third parties. The app contains no advertising, analytics, or marketing SDKs.

4. Data Retention and Deletion

All data is stored on the user's device. Deleting the app removes all locally stored data. The developer does not retain any user data.

5. Children's Privacy

This app is not directed at children under the age of 13 and does not knowingly collect personal information from children.

6. Third-Party App Disclaimer

BYD AutoLock is an independent third-party app and is not made or endorsed by BYD. It uses BYD's publicly accessible API, and users authenticate directly with their own BYD accounts.
