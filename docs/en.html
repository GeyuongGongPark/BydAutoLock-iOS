Features

Everything you need.

Real vehicle control via BYD's official API.

🔓

Auto Unlock

Automatically unlocks your vehicle when BLE RSSI exceeds the threshold as you approach.

🔒

Auto Lock

Automatically locks when you walk away. Even after an unlock, a scheduled lock fires after the cooldown expires.

📡

EMA Signal Filter

Exponential moving average combined with linear regression outlier detection for stable, noise-free distance measurement.

❄️

Auto A/C Control

Automatically turns A/C on when unlocking and off when locking. Configurable temperature and fan speed.

📍

Parking Location

Periodically queries vehicle GPS to record the last parking spot, viewable on Apple Maps.

⌚

Apple Watch

Check lock status, manually lock/unlock, and toggle service from your wrist. Complications supported.

🔲

Home Screen Widgets

Small/Medium home screen widgets and Lock Screen widgets showing lock status and battery at a glance.

🗺️

Geofencing

Automatically stops BLE scanning when you leave a 150m radius of your parking spot, saving battery.

📶

Signal Loss Protection

A grace timer prevents false actions when BLE drops. Driving detection also blocks false triggers.

🧘

Stationary Detection

Pauses BLE scanning after 5 minutes of no movement. Automatically resumes when motion is detected.

🚗

Trunk Remote Control

Open and close the trunk with one tap. Also controllable via Siri voice commands.

🎙️

Siri Voice Control

"Open BYD AutoLock trunk" — hands-free vehicle control. Also supports lock, unlock, and A/C.

✅

Lock Result Verification

Checks actual vehicle state 35 seconds after auto lock/unlock. Retries and notifies on failure.

📶

BLE Direct Control

Lock/unlock directly via BLE without internet. Self-approval registration — no QR scan required.

How It Works

How does it work?

It measures your vehicle's BLE signal strength (RSSI) to estimate distance.

1

BLE Signal Detection

The app connects to your vehicle's BLE device in the background and measures RSSI every 3 seconds — reliably, even when the app is not in the foreground.

2

Distance Estimation

An EMA filter is applied to the raw RSSI to remove noise. The smoothed value is compared against your configured thresholds to determine approach or departure.

3

Vehicle Control Command

Lock/unlock commands are sent via BYD's official API. Results are confirmed and delivered as notifications.

4

Auto A/C (Optional)

When unlocking, the app automatically turns on A/C to your configured temperature — so the cabin is comfortable before you even get in.

Install

Choose your install method

Pick the method that works best for you.

Install IPA with AltStore or Sideloadly

Install for free using just your Apple ID — no paid developer account needed. Requires re-signing every 7 days.

1

Install AltStore

Install AltStore on your Mac or Windows PC. Alternatively, use Sideloadly.

2

Download the IPA

Download the latest BydAutoLock.ipa from the GitHub Releases page.

→ Download from GitHub Releases

3

Install on iPhone

Connect your iPhone to your Mac/PC and use AltStore to select and install the IPA file.

4

Trust the Developer

Go to Settings → General → VPN & Device Management and trust the developer certificate.

⚠️

A free Apple ID requires re-signing every 7 days. Use AltStore's auto-renewal feature, or a paid Apple Developer account ($99/year) for a 365-day certificate.

Build with Xcode

For developers who want to modify the source code or build it themselves.

1

Clone the Repository

git clone https://github.com/GeyuongGongPark/BydAutoLock-iOS.git cd BydAutoLock
2

Open in Xcode

open BydAutoLock.xcodeproj
3

Set Signing Team

Select the BydAutoLock target in Xcode → Signing & Capabilities → set Team to your Apple ID.

4

Build and Run

Connect your iPhone, select it as the target device, and press ⌘R to build and install.

5

Trust the Developer

Go to Settings → General → VPN & Device Management and trust the developer certificate.

⚠️

Requires Xcode 15 or later and macOS 13 or later. Builds signed with a free Apple ID expire after 7 days and must be rebuilt.
